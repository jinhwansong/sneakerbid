# LaceUp 프론트엔드 주요 문제 정리

> 기능 설명이 아닌, 실제로 발생했던 문제와 그 영향 중심으로 정리

---

## 1. SSE 메시지 핸들러가 오래된 상태를 참조하는 문제

| 구분 | 내용 |
|------|------|
| **어떤 문제** | `EventSource.onmessage`에 바인딩된 `onMessage` 콜백이 `useEffect` 클로저에 갇혀, 리렌더 시 갱신된 state/props를 참조하지 못함 |
| **왜 문제인지** | SSE로 새 입찰이 들어와도 핸들러가 초기 렌더 시점의 `bidHistory`, `setBidHistory`만 보고 있어, 최신 입찰이 누락되거나 중복·잘못된 값으로 반영됨 |
| **사용자 영향** | 입찰 피드에 새 입찰이 안 보이거나, 잘못된 금액/순서로 표시됨. 실시간 경매에서 현재가·입찰 이력 신뢰도 하락 |

---

## 2. 401 토큰 만료 시 무한 재시도 루프

| 구분 | 내용 |
|------|------|
| **어떤 문제** | API 401 → refresh 호출 → refresh도 401(만료) → 원래 요청 재시도 → 401 → refresh → … 반복 |
| **왜 문제인지** | refresh 실패 시에도 재시도 로직이 계속 돌아가며, 종료 조건이 없어 브라우저가 무한 요청에 빠짐 |
| **사용자 영향** | 탭 멈춤·느려짐, 네트워크 탭에 요청 폭주. 로그인 만료 시 재로그인 유도 대신 앱이 먹통처럼 보임 |

## 3. 현재가 표시 불일치 (SSE vs 서버 응답 순서)

| 구분 | 내용 |
|------|------|
| **어떤 문제** | 내 입찰 직후, 서버 응답의 `currentPrice`와 SSE로 들어온 다른 사용자 입찰의 `currentPrice`가 서로 다른 시점을 반영해, 화면에 표시되는 현재가가 실제보다 낮을 수 있음 |
| **왜 문제인지** | 네트워크 지연으로 SSE 이벤트가 먼저 도착하면 `currentPrice`는 아직 이전 값. 반대로 서버 응답이 먼저 오면 SSE의 더 높은 입찰이 반영되지 않음 |
| **사용자 영향** | 실제보다 낮은 현재가를 보고 입찰해 경쟁에서 밀리거나, 이미 낙찰된 경매에 입찰 시도하는 등 잘못된 의사결정 유발 |

---

## 4. 결제 모달 중간 종료로 인한 불완전 주문

| 구분 | 내용 |
|------|------|
| **어떤 문제** | 즉시구매 시 "주문 생성" API 성공 후 "결제" 단계로 넘어가기 전에 사용자가 모달을 닫을 수 있었음 |
| **왜 문제인지** | 주문은 PENDING 상태로 DB에 남았지만 결제는 진행되지 않아, 미결제 주문이 그대로 쌓이고 사용자는 진행 상황을 알 수 없음 |
| **사용자 영향** | 내 주문 목록에 "결제 대기" 상태가 계속 남고, 해당 경매는 다른 사람에게 낙찰될 수 있어 혼란과 불만 발생 |

---

## 5. SSE 연결 끊김 시 실시간 데이터 미수신

| 구분 | 내용 |
|------|------|
| **어떤 문제** | 네트워크 불안정·서버 재시작 등으로 `EventSource` 연결이 끊기면, 재연결 없이는 이후 입찰·거래 이벤트를 받지 못함 |
| **왜 문제인지** | EventSource는 단방향 연결이라 끊기면 클라이언트가 새 연결을 맺지 않는 한 이벤트 수신 불가 |
| **사용자 영향** | 화면의 입찰 피드·현재가가 멈추고, 새로고침 전까지 실시간처럼 보이지 않음. 경매 마감 직전 정보 부재로 입찰 기회 상실 |

---

## 6. 재연결 중임을 사용자에게 알리지 못함

| 구분 | 내용 |
|------|------|
| **어떤 문제** | SSE 재연결을 구현했지만, 재연결 중인지 사용자에게 알리는 UI가 없었음. 경매 상세·거래내역 등 여러 SSE 채널이 동시에 있을 때 상태 집계도 애매함 |
| **왜 문제인지** | 재연결 중에는 이벤트를 받지 못하므로 데이터가 멈춘 것처럼 보이는데, "연결 끊김"인지 "진짜 이벤트가 없는 것"인지 구분 불가 |
| **사용자 영향** | 데이터가 안 들어오는 이유를 모르고 새로고침하거나, 앱이 고장난 것으로 오해할 수 있음 |
